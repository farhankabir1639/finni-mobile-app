# 🐬 Finni — AI-Powered Personal Finance App

> **Talk to your money. Finni listens.**

Finni is a conversational AI-first personal finance app built with React Native and Expo. Instead of manually entering expenses into spreadsheets or tapping through menus, you simply tell Finni what you spent — and it handles everything automatically.

---

## ✨ Features

- 💬 **Natural Language Expense Logging** — Just say "Spent $12 on lunch" and Finni logs it instantly
- 🧠 **AI-Powered Categorization** — Automatically maps transactions to categories using semantic analysis (powered by Gemini 2.5 Flash)
- 📊 **Smart Analytics** — Visual spending breakdowns by category, monthly trends, and date filters
- 💡 **AI Insights** — Daily spending summaries and savings recommendations generated by AI agents
- 🗂️ **Dynamic Categories** — AI proposes and creates new categories on the fly when none match
- 🎯 **Financial Goals** — Set and track savings goals linked to categories
- 🔄 **Real-time Updates** — Transactions and stats update instantly across all screens
- 🔐 **Secure Auth** — Supabase-powered authentication and database

## 🤖 AI Agent Architecture

Finni uses a **multi-agent system** powered by Gemini:

| Agent | Role |
|---|---|
| Agent 1 — Chat | Intent detection, expense logging, categorization |
| Agent 2 — Insights | Daily transaction analysis and summaries |
| Agent 3 — Savings | Weekly savings optimization recommendations |
| Agent 4 — Localization | Currency and locale formatting |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Expo CLI
- Supabase account
- Google AI Studio API key (Gemini)

### Installation

```bash
git clone https://github.com/farhankabir1639/finni-mobile-app.git
cd finni-mobile-app
npm install
```

### Environment Setup

Create a `.env` file in the root directory:

```env
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
EXPO_PUBLIC_GEMINI_API_KEY=your_gemini_api_key
```

### Run the App

```bash
npx expo start
```

Scan the QR code with Expo Go on your phone, or press `i` for iOS simulator / `a` for Android emulator.
